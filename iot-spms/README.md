# IoT-SPMS - Smart Parking Management System for University Campus

## Project Overview
This repository contains the Software Engineering report workspace and a React/Vite MVP implementation for the IoT-based Smart Parking Management System. The MVP simulates authentication, parking sessions, temporary tickets, IoT occupancy updates, billing, policy configuration, and audit logs using mock data.

## Folder Structure
- docs/report: Report draft files organized by assignment tasks and final sections.
- docs/references: Assignment notes, feedback notes, and bibliography placeholders.
- docs/assets: Screenshots, exported diagrams, and UI mockup assets.
- diagrams: PlantUML source files grouped by task and diagram type.
- mvp: MVP source skeleton for later implementation.
- tests: Test case and traceability templates.
- scripts: Instructions for rendering diagrams and exporting report assets.

## Diagram Organization
All diagram source files are under diagrams/ as .puml files:
- task1_use_case_diagrams
- task2_ui_flows
- task2_sequence_diagrams
- task2_activity_diagrams
- task2_state_charts
- task3_architecture_diagrams
- task3_class_diagrams

Generated diagram images should be stored in docs/assets/exported_diagrams.

## MVP Source Code Guidance
The mvp/ folder contains placeholder files for pages, components, services, data, and app entry files.
Add implementation incrementally in later milestones.
Avoid adding full production logic before requirements and design artifacts are finalized.
